# hadeed-privacy

The public site for **Hadeed** (حديد), the offline gym workout planner and log: the privacy
policy, the install pages and the feature pages. Static files on GitHub Pages, served and
canonical on mohamedgado.com, which proxies this repo (`hadeed.mohamedgado.com` is the
install host).

**Install:** <https://hadeed.mohamedgado.com/> · [App Store](https://apps.apple.com/app/id6837665349) · [Google Play](https://play.google.com/store/apps/details?id=com.mohamedgado.hadeed)
**Policy:** <https://www.mohamedgado.com/projects/hadeed/privacy> (also at <https://vette1123.github.io/hadeed-privacy/>)
**Package:** `com.mohamedgado.hadeed` · **App repo:** `Flutter/hadeed`
**Contact:** booogado@gmail.com

The site is the same kit as masareef-privacy, rafiq-privacy and nafis-privacy (nafis is the
copy this one was ported from): same partials, header, footer, install-page template, feature
page builder and SEO gate. A change to the shared look goes into all four.

## What lives in this repo

| File | Purpose |
| --- | --- |
| `index.html` | The whole policy, Arabic (`#doc-ar`, RTL) and English (`#doc-en`) in one document. `#delete` / `#delete-ar` are the data-deletion anchors the store listings and footers link. |
| `go.html`, `go-ar.html` | **Generated, never edit by hand.** The install pages (store chooser, SEO copy, hreflang, JSON-LD). `/go` is printed in share-card QR codes: the path never changes. |
| `go.template.html`, `go.copy.json`, `scripts/build-go.mjs` | Their sources. Every claim in `go.copy.json` traces to the store listing (`Flutter/hadeed/store/metadata`, `store/ios/listing`). |
| `go-img/`, `og.jpg`, `icon.png` | Generated by `pnpm site:go-art` in the app repo (`store/compose-go-art.cjs`): phone shots in English and Arabic (`<name>-480/720` and `<name>-ar-480/720`, AVIF + WebP), icons, and the 2400x1260 link-preview card. The store badges are official files: never redraw them. |
| `features/`, `features/en/` | **Generated.** One Arabic and one English page per feature (8 + a hub each). Sources: `scripts/features-data.mjs` (the words), `scripts/components.mjs`, `partials/feature.css`. Run `node scripts/build-features.mjs`; it also writes the slug list to `portfolio-v1/content/hadeed-feature-pages.json`. |
| `partials/` | The shared look: theme (Hadeed's iron-and-copper palette), the one header, both footers, language and theme switches. `node scripts/build-pages.mjs` fills them into `index.html` and `404.html`. |
| `scripts/check-site.mjs` | The SEO gate: unique titles, descriptions and canonicals, lengths, og/twitter tags, JSON-LD parses, reciprocal hreflang, internal links resolve. |
| `scripts/build-sitemap.mjs`, `sitemap.xml`, `lastmod.json` | Every indexable page at its canonical URL, dated from `lastmod.json`, which the lastmod workflow writes from git. |
| `.github/workflows/` | `deploy-portfolio.yml` rebuilds mohamedgado.com on push (`CF_DEPLOY_HOOK` secret), `indexnow.yml` pings changed pages, `lastmod.yml` dates them. |
| `404.html` | Sends a wrong path back to the site. |
| `review/` | Store-review material, not indexed (`robots.txt`). |

`npm run build` regenerates everything; `npm run check` is the gate (every generator in
`--check`, the SEO gate, the tests). No dependencies.

## What the policy must keep true

- **Permissions** list the merged release manifest: the app's own plus what plugins add
  (`local_auth` adds `USE_BIOMETRIC`). Re-check after a dependency change.
- **iPhone** asks for camera, photos and Face ID; each is described in section 4.
- **Analytics:** PostHog EU, counts and choices only, never workouts, weights, notes or food.
  The page footers disclose the cookieless count on mohamedgado.com; keep them in step.
- If the app ever sends something new, update the policy before that version ships.
